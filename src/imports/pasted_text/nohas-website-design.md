# NOHAS Website — Figma UI/UX Design Prompt
**National Oral Health Awareness Society | 2026–2027**
---

## Project Context

Design a complete, high-fidelity website for NOHAS (National Oral Health Awareness Society), a professional health-awareness organization dedicated to promoting oral health education across Pakistan. The tone of the brand is clean, trustworthy, nature-inspired, and modern — not clinical or sterile. The website must feel premium, approachable, and socially impactful.

---

## Brand System — Apply Exactly as Specified

### Color Palette

| Role | Name | Hex |
|---|---|---|
| Primary / Main Brand | Forest Green | `#2F5E3A` |
| Secondary Green | Sage Green | `#7A9A7A` |
| Soft Accent | Eucalyptus | `#BFD3C1` |
| Primary Background | Ivory Beige | `#F5F2E8` |
| Secondary Background | Warm Sand | `#E7DECA` |
| Neutral Element | Stone | `#A8A193` |
| Primary Text | Charcoal | `#2B2B2B` |
| Heading / Strong Text | Jet Black | `#111111` |

**Color Rules:**
- Page backgrounds alternate between Ivory Beige `#F5F2E8` and Warm Sand `#E7DECA`
- All primary CTAs use Forest Green `#2F5E3A` with white text
- Secondary CTAs use an outlined style with Forest Green border and Forest Green text
- Hover states darken the Forest Green by 10%
- Section dividers use Eucalyptus `#BFD3C1` or a thin Stone line
- Never use pure white `#FFFFFF` as a background — always use Ivory Beige instead

### Typography

| Type | Font | Weight | Size Range |
|---|---|---|---|
| H1 / Hero Heading | Cormorant Garamond | Regular / SemiBold | 56–72px |
| H2 / Section Title | Cormorant Garamond | SemiBold | 36–48px |
| H3 / Card Title | Montserrat | SemiBold | 20–24px |
| H4 / Label / Tag | Montserrat | SemiBold | 14–16px (tracking: +0.08em uppercase) |
| Body / Paragraph | Lato | Regular | 16–18px, line-height: 1.7 |
| Caption / Fine Print | Lato | Regular | 12–14px |
| Button Text | Montserrat | SemiBold | 14px, uppercase, tracking: +0.1em |

**Typography Rules:**
- All section labels above headings use Montserrat SemiBold, uppercase, letter-spaced, in Forest Green
- Body text color is Charcoal `#2B2B2B`
- Headings use Jet Black `#111111`
- Minimum body line-height is 1.7 for readability
- Never use font sizes below 14px for any visible UI text

### Spacing System (8pt Grid)

Use an 8pt base grid throughout. Common spacing tokens:

- XS: 8px
- S: 16px
- M: 24px
- L: 40px
- XL: 64px
- XXL: 96px
- Section vertical padding: 80px top and bottom (desktop), 48px (mobile)

### Decorative Elements

The brand uses a small 4-pointed sparkle/diamond symbol (✦) as a decorative accent. Use it:
- As a section divider between a label and a heading
- As a bullet alternative in highlight lists
- In footers and horizontal rules
- Color: Forest Green or Stone depending on background

## UX Patterns & Interaction Notes

These should be annotated in Figma using the Prototype tab or sticky notes:

- Navbar becomes sticky on scroll and gains a drop shadow after 60px scroll
- All card hover states: lift 4px (translate Y), add soft box shadow `0 8px 24px rgba(47, 94, 58, 0.12)`
- All CTA buttons have a hover state that darkens background by 10%
- "Read More" and arrow links animate the arrow 4px to the right on hover
- Event cards show a subtle left border in Forest Green on hover
- Mobile menu slides in from the right as a full-screen drawer over Ivory Beige
- Newsletter input shows Forest Green outline and a subtle scale-in effect on focus
- Form submit button shows a loading spinner state and a success state (green checkmark + "Thank you!" message)
- All page transitions: fade in on scroll using opacity 0 to 1 + slight upward translate (for dev handoff notes)

## Responsive Design Notes (Mobile)

Apply these rules when designing mobile frames:

- All multi-column layouts collapse to single column
- Impact Stats: 2×2 grid on mobile
- Nav collapses to hamburger icon, opens full-screen drawer
- Hero: text stacks above image, font sizes reduce (H1 → 36–40px)
- Cards: full-width with 16px horizontal margin
- Buttons: full-width on mobile for primary CTAs
- Footer: single column stacked, logo centered, links stacked
- Section vertical padding reduces to 48px on mobile
- Font size for body: 15px minimum on mobile

## Design Quality Checklist

Before finalizing each page, verify:

- [ ] All text passes WCAG AA contrast ratio (4.5:1 minimum for body text)
- [ ] No background uses pure white — always Ivory Beige or Warm Sand
- [ ] All interactive elements have visible hover and focus states
- [ ] Consistent 8pt spacing applied throughout
- [ ] All components are from the shared component library (no detached instances)
- [ ] Section labels always appear above their corresponding H2 in Forest Green Montserrat uppercase
- [ ] Sparkle decorative elements used consistently in section dividers
- [ ] No Lorem Ipsum — use real placeholder content relevant to oral health
- [ ] Icons are consistent in style (outline/line style, not filled) across all pages
- [ ] Mobile frame created for Home page and at least one interior page
